
# XSSHunter-Express Debian Setup Guide

> **XSSHunter-Express** is a self-hosted tool for detecting and monitoring **Blind XSS payload executions**.
> This guide walks through installation, configuration, and securing your deployment.

📂 GitHub Repository: [XSSHunter-Express](https://github.com/mandatoryprogrammer/xsshunter-express)

---

## 1. Prepare Hostname and System

Set a recognizable hostname for your server:

```bash
vim /etc/hostname
```

Example:

```
xssht.nikhil.local
```
> Save - :wq
Update system packages:

```bash
apt update
```

(Optional) Check if Docker is already installed:

```bash
netstat -nltup | grep docker
dpkg -l | grep -i docker
```

## 2. Install Docker and Docker Compose

Install Docker:

```bash
apt install docker.io docker-compose
```

Enable and start Docker:

```bash
 systemctl enable docker
 systemctl restart docker
 systemctl status docker
```

Confirm Docker is listening:

```bash
netstat -nltup | grep docker
dpkg -l | grep -i docker
```

## 3. Clone XSSHunter-Express Repository

Navigate to `/opt` (or any preferred directory):

```bash
cd /opt
```

Clone the repository:

```bash
 git clone https://github.com/mandatoryprogrammer/xsshunter-express.git
cd xsshunter-express
```

## 4. Configure `docker-compose.yml`

Open the config file:

```bash
 vim docker-compose.yml
```

### Key Environment Variables

* `HOSTNAME` → Your server hostname/domain (must resolve to server’s IP).
* `SSL_CONTACT_EMAIL` → For Let’s Encrypt certificate notifications.
* `MAX_PAYLOAD_UPLOAD_SIZE_MB` → Limit for captured payload data.
* `CONTROL_PANEL_ENABLED` → `true` to enable dashboard, `false` for headless mode.
* **SMTP Settings** → Configure email notifications.
* **Database Settings** → Postgres DB credentials.

### Volumes

* `./ssldata` → SSL certs (auto-renewed).
* `./payload-fire-images` → Screenshots of executed payloads.
* `./postgres-db-data` → Persistent Postgres data.

### Example Config

```yaml
environment:
  - HOSTNAME=xssht.nikhil.local
  - SSL_CONTACT_EMAIL=xssht@nikhil.local
  - MAX_PAYLOAD_UPLOAD_SIZE_MB=50
  - CONTROL_PANEL_ENABLED=true

  # SMTP Settings
  - SMTP_EMAIL_NOTIFICATIONS_ENABLED=true
  - SMTP_HOST=smtp.mail.yahoo.com
  - SMTP_PORT=465
  - SMTP_USE_TLS=true
  - SMTP_USERNAME=xsshtnikhil@yahoo.com
  - SMTP_PASSWORD=your_email_password_here
  - SMTP_FROM_EMAIL=xsshtnikhil@yahoo.com
  - SMTP_RECEIVER_EMAIL=xsshtnikhil@yahoo.com

  # Database Settings
  - DATABASE_NAME=xsshtdb
  - DATABASE_USER=xsshunterexpress
  - DATABASE_PASSWORD=xsshunterexpress123
  - DATABASE_HOST=postgresdb
```


## 5. Start Services

Start Postgres container first:

```bash
 docker-compose up -d postgresdb
```

Then start XSSHunter-Express:

```bash
 docker-compose up -d xsshunterexpress
```

Check logs if issues arise:

```bash
 docker-compose logs -f xsshunterexpress
```

## 6. Access Web Control Panel

If `CONTROL_PANEL_ENABLED=true` →
Open browser:

```
https://xssht.nikhil.local
```

---

## Best Practices

*  **Secure SMTP Credentials** → Use Docker secrets/env files, not plaintext in YAML.
*  **Firewall** → Allow ports `80` & `443` only.
*  **SSL Certificates** → Auto-renew via Let’s Encrypt (ensure DNS points correctly).
*  **Database Security** → Change default Postgres creds & don’t expose publicly.
*  **Backups** → Regularly backup `postgres-db-data` and `payload-fire-images`.
